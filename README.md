# 🌳 Prime Factorization Tree (Interactive Web App)

An interactive, responsive, and fully localized web application that visualizes the prime factorization process of any given integer using a dynamic animated Factor Tree.

## ✨ Features
* **Visual Factor Tree:** Generates an animated step-by-step breakdown tree for any input number > 1.
* **20 Languages Supported:** Includes Georgian, English, Spanish, French, German, Italian, Portuguese, Dutch, Polish, Russian, Ukrainian, Turkish, Azerbaijani, Armenian, Greek, Chinese, Japanese, Korean, Arabic, and Hindi.
* **Real-time Statistics:** Displays input number, prime factors, factor count, and unique primes.
* **Interactive UI:** Smooth CSS animations, responsive layout for mobile and desktop, and prime node highlighting with checkmarks.
* **Zero Dependencies:** Pure HTML, CSS, and vanilla JavaScript — no external frameworks required.

## 🚀 Live Demo
You can run this project directly via GitHub Pages:
`https://<your-username>.github.io/<your-repo-name>/`

## 🛠️ Usage
1. Open `index.html` in any web browser.
2. Select your preferred language from the dropdown menu.
3. Enter any integer greater than 1 (e.g., `88`).
4. Click **Calculate** to see the interactive prime factorization tree!
